# Zainab Memorial Academy timetable
Open the folder in VS Code, right-click index.html, choose "Open with Live Server" (or double-click index.html).
Logins: admin / ZMAK123 | students: ss2 / ZMA-SS2 (same pattern for every class) | demo teacher: teacher / teacher123
Edit school details and the starting timetable in data.js. Admin changes are saved in the browser.

Teachers: the admin adds phone, email, subjects and classes. Students tap any subject to see its teacher. Only the admin can reset passwords (Admin page). Use the Light/Dark button at the top. Teacher lesson alerts (7:00 summary, 5 minutes before start and end) show while the teacher page is open.

## What's new
- Admin tabs: Periods, Teachers, Courses & Classes, Alerts, Settings & Log.
- Admin sees every teacher and class password (Show passwords button), can reset or generate new ones. Only the admin can change passwords.
- Admin can add/remove classes and courses; backup/restore; activity log.
- Alerts have an admin ON/OFF switch plus options (7:00 digest, 5 min before start/end) and a day preview.
- Teachers: tap any period for details; weekend notice. Students: weekend notice, instant updates in other open tabs of the same browser.
- Still needed (needs a school server): updates across different phones, and alerts by email/SMS/push when the page is closed.
